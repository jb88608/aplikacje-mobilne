# lab_05 – Podstawowe komponenty Ionic React

Link do aplikacji: https://lab05-bonda.web.app/

## Uruchomienie

1. Sklonuj repozytorium:
   ```bash
   git clone https://github.com/jb88608/aplikacje-mobilne.git
   ```
2. Przejdź do folderu projektu:
   ```bash
   cd lab_05
   ```
3. Zainstaluj zależności:
   ```bash
   npm install
   ```
4. Uruchom aplikację:
   ```bash
   ionic serve
